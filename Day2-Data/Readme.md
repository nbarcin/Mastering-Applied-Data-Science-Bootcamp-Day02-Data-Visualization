# Day 02 – Data Visualization & Exploratory Data Analysis

**Mastering Applied Data Science Bootcamp**

## Project Overview

This notebook explores data visualization and exploratory data analysis (EDA) using Python. It demonstrates how to import, inspect, clean, analyze, and visualize datasets using popular Python libraries.

The project includes a supermarket sales analysis, financial market data visualization, Google Trends exploration, and examples of static, interactive, and advanced charts.

## Topics Covered

### 1. Python Fundamentals

* Variables, data types, operators, and conditional statements
* Loops, functions, and list comprehensions
* Basic object-oriented programming (OOP)
* Text-to-speech conversion using `gTTS`

### 2. Data Handling with Pandas

* Importing CSV datasets with `pd.read_csv()`
* Exploring datasets with `.head()`, `.tail()`, `.shape`, and `.info()`
* Identifying missing values with `.isnull().sum()`
* Calculating descriptive statistics with `.describe()`
* Handling missing values with `.fillna()`
* Creating new features through feature engineering
* Analyzing categorical data with `.value_counts()`
* Exporting data to Excel

### 3. Exploratory Data Analysis (EDA)

* Examining dataset structure and data types
* Calculating mean, median, mode, standard deviation, and variance
* Exploring distributions and relationships between variables
* Analyzing numerical and categorical features

### 4. Data Visualization

Practiced a variety of visualization techniques using Matplotlib, Seaborn, Pandas, and Plotly:

* Line plots and scatter plots
* Histograms and KDE plots
* Count plots and pie charts
* Box plots and violin plots
* Correlation heatmaps
* Pair plots and swarm plots
* Area plots and radar charts
* Sunburst, donut, and Sankey diagrams
* 3D scatter and surface plots

### 5. Supermarket Sales Analysis

* Exploring supermarket sales data
* Analyzing sales by month, weekday, branch, gender, payment method, and product line
* Extracting date and time features
* Investigating customer ratings, transaction totals, and product quantities
* Visualizing relationships and distributions in the dataset

### 6. Financial and Trend Data Visualization

* Downloading historical stock market data with `yfinance`
* Comparing closing prices for selected stocks
* Exploring search interest over time using `pytrends`
* Visualizing population trends across world regions
